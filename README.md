РемКомСтрой - ремонт комплексных строений

Основные бизнес процессы:
1) Тендер
1.1) указывается, что необходим ремонт какого то элемента (пример - окна в здании)
1.2) система смотрит на зависимые подчасти (например чтобы поменять окно дальше нужно еще заштукатурить стену)
1.3) по каждому из необходимых действий рассылаем тендеры подрядчикам, способным это выполнить
1.4) после получения ответов анализируем эти ответы + данные о том как подрядчик раньше себя показывал 
1.5) администратор выбирает подрядчиков на каждый этап


2) Изменения списка необходимого ремонта (пример - подрядчик ремонтируя окно понял, что сначала нужно починить стену)
1.1) подрядчик инициирует необходимость еще какого то ремонта
1.2) этот доп ремонт утверждается и создается еще тендер (если текущий подрядчик может сам то просто ему это тоже дается), сроки двигаются
